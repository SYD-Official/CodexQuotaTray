# Codex 用量（Windows）

一个只读的 Windows 额度小工具，用来显示 Codex 当前账户额度和本地 token 活动。

## 使用方法

1. 先启动 Codex 桌面应用。
2. 双击最新的版本化 EXE，例如 `CodexQuotaTray-v2.6.0.exe`。
3. 点击任务栏数字条或右下角托盘图标查看详情；右键可以刷新或退出。

本工具不会替你启动、登录或控制 Codex。Codex 运行时，程序通过已安装的 Codex 只读接口获取当前额度；Codex 没有运行时，数字条显示离线。

## 新版界面

- 双额度：固定识别 300 分钟的 5 小时额度和 10080 分钟的每周额度，5 小时额度作为主显示，周额度作为长期约束辅助显示。
- 备用额度：常规额度可用时保持原有显示；只有常规额度不可用或 `gpt-reserve` 已开始消耗时，才自动显示备用额度及其剩余量。
- 额度布局：详情页默认突出 5 小时主进度条并使用较小的周额度条，也可在一级“设置”切换为两条等大布局。
- 时间剩余：按额度窗口时长和重置时间计算剩余百分比。
- 节奏状态：为短时突发使用预留 20 个百分点缓冲；只有额度消耗比时间进度超前超过 20 个百分点时才提示“消耗偏快”，否则显示“节奏正常”。
- 重置信息：同时显示倒计时和本地绝对时间。
- Token 活动：汇总本机 Codex 会话文件中的 token 累计值，可切换当前 5 小时额度周期、24 小时、7 天和 30 天柱状图。5 小时视图按额度重置边界固定为 30 个十分钟位置，并根据同一会话内连续累计值的正增量分桶；它不是滚动最近 5 小时，周期开始时为空，并随时间从左向右推进。
- 柱状图交互：5小时与24小时视图显示5小时额度变化，7天与30天视图显示周额度变化；悬停提示会明确标注口径。额度百分比按对应窗口的“剩余百分比下降量”计算，没有足够快照时显示 `--`，不会误报成 `0%`。当前柱与相邻柱通过缓动形成连续波峰。
- 跨重置累计：例如先从 50% 剩余降到 20%，中途重置后再从 100% 降到 50%，区间消耗为 `30% + 50% = 80%`；重置补回的额度不计为负数。
- 套餐类型：优先使用 Codex 当前额度响应中的 `planType`；字段为空时，只读解码本机 `auth.json` 中 ID Token 的 `chatgpt_plan_type` 声明作为兜底。仍没有真实值时整行隐藏。
- 设置：一级页面包含任务栏数字条、额度主次布局、四套强调色预设、双颜色自定义以及语言；“更多设置”包含三项尺寸、柔光玻璃开关及其下一行的不透明度、任务完成闪烁提醒、版本更新和作者链接。任务完成提醒默认关闭，柔光玻璃默认开启，关闭后不透明度滑杆会禁用。外观默认使用浅色，仍可切换深色或跟随系统；语言跟随系统时读取 Windows 首选界面语言，中文以外的语言回退为 English。所有可点击选项均有独立悬停反馈。
- 任务栏数字条：在 Windows 通知区域左侧显示完整的 5 小时余额百分比，大环下方显示距重置小时数（如 `3.6H`），右侧周额度小环内显示余额整数；可在设置中关闭。
- 弹窗位置：读取托盘图标或数字条的完整边界，以图标圆心为水平中线，在任务栏上方展开；鼠标点在图标哪一侧都不会改变中线。
- 即点即开：点击任务栏数字条时先立即显示已有额度快照，再在后台刷新，不再等待网络读取完成。

“本地 token”不是 OpenAI 账户后台的官方统计，而是本机现存会话记录的只读汇总。删除过的会话、其他电脑上的会话不会包含在内。

设置自动保存在 `%LOCALAPPDATA%\CodexMeter\settings.ini`，用于额度变化图表的只读历史快照保存在 `%LOCALAPPDATA%\CodexMeter\quota-history-v1.tsv`。

## DPI 与界面尺寸

程序声明为 Per-Monitor V2 DPI 应用，并处理运行中的 `WM_DPICHANGED`：把窗口拖到不同缩放比例的显示器、修改 Windows 缩放或换电脑后，会按新 DPI 重新计算像素尺寸并重绘。

“更多设置”页可以用连续滑杆分别调整悬浮窗、字体、任务栏数字条和柔光玻璃不透明度。滑杆顶部显示跟随滑块移动的数值；松开时靠近推荐值会自动吸附，并通过数值上弹和圆点高亮反馈。四个滑杆左侧标签按上下分隔线形成的整行精确垂直居中。系统托盘额度图标始终保持单环；任务栏数字条使用大环和大数字显示 5 小时余额，大环内侧的小环表示该窗口的重置倒计时，大数字下方显示距重置小时数；右侧周额度环保持单环并显示余额整数。额度环分别按自身余额告警：剩余 11%～20% 时变为橙色，剩余不超过 10% 时变为红色。

柔光玻璃使用 Windows 桌面合成器生成会随桌面变化的动态 Acrylic 背景，默认开启、不透明度为 40%；滑杆现在直接控制玻璃遮罩的不透明度，低值会显示更多后方内容。文字由独立的透明 DirectWrite 灰阶图层绘制，不随玻璃一起变淡，并避免透明表面使用 ClearType 时产生彩边。窗口仍优先采用 DWM 原生圆角，避免圆角黑底。一级设置右上角为“恢复默认”，左下角为“返回首页”；所有纯文字按钮的命中范围仅覆盖文字附近。弹窗关闭后再次打开始终从首页开始。任务栏数字条每秒进行一次无焦点层级自检；每次余额刷新还会在全新的后台自动化线程中重新读取程序按钮组与通知区边界，绕过 Windows 11 的旧坐标缓存，图标增减后会自动向左或向右跟随。

## Windows 状态区说明

Windows 原生 `NotifyIcon` 只提供一个方形图标和悬停提示，不能在图标右侧常驻任意文字。本工具因此同时提供：

- 托盘圆环图标：单圆环表示当前最紧张额度，中心数字仍是该额度余额；启用任务完成提醒后，存在未读完成任务时会叠加蓝点并闪烁。
- 任务栏数字条：左侧大环和大数字固定表示 5 小时余额，大环内的小环表示 5 小时窗口重置倒计时，其下显示距重置小时数；右侧周额度保持单环，环内显示不带百分号的余额整数。
- 任务栏数字条：作为任务栏拥有的无激活置顶窗口贴合在通知区域左侧，不抢焦点，完整显示 5 小时百分比。置顶属性用于避免 Windows 11 任务栏合成层遮挡。

Windows 没有向普通应用开放常驻任务栏文字槽，因此数字条仍不是系统原生通知图标。程序将数字条设为任务栏的拥有窗口，避免 Windows 11 合成层遮住普通子窗口；同时在 Explorer 重启、任务栏移动或分辨率变化后重新连接和定位。守护检查只在位置或置顶状态真正变化时调整窗口，避免定时重复抢占截图遮罩层或触发任务栏重新合成。

## 数据更新

程序每 20 秒通过已安装的 `codex app-server` 调用只读的 `account/rateLimits/read`，获取与 Codex 当前用量页相同口径的 5 小时、每周额度和备用额度。常规额度可用且备用额度尚未消耗时维持原有的 5 小时与每周额度显示；只有常规额度不可用或 `gpt-reserve` 已开始消耗时，才把备用额度显示为当前长期额度。旧版 `sessions` 额度快照仅作为接口暂时不可用时的兼容兜底。Token 活动仍从本机会话文件汇总，并每 5 分钟重新扫描一次。

额度刷新会短暂启动已安装的 `codex app-server`，只发送初始化和 `account/rateLimits/read` 请求，收到结果后立即结束子进程；身份验证由 Codex 自身处理。本工具不会读取、保存、上传或显示 ID Token、access token、refresh token、邮箱或账户 ID。仅当额度响应缺少套餐字段时，才会只读打开 `auth.json`，在内存中解码 ID Token 载荷并只取 `chatgpt_plan_type`。本地 token 活动仍只读访问 `sessions`。

任务完成闪烁提醒默认关闭。开启后，程序只增量读取 Codex 桌面日志中的 `turn-complete`、`conversationId`、`turnId` 和 `resumeState` 状态字段，不读取或显示任务正文。空闲时每 20 秒检查一次；发现未读完成任务后每 3 秒检查，直到对应任务变为已读。也可以点击本工具托盘图标或任务栏数字条，立即清除当前闪烁提醒。

## 检查更新

在“设置 → 更多设置”中点击“检查更新”，程序才会连接 GitHub 查询 `SYD-Official/CodexQuotaTray` 的最新正式发布。当前已是最新版时只在页面内显示状态，不弹出对话框；发现新版本后会询问是否下载。下载文件会保存到 `%LOCALAPPDATA%\CodexMeter\Updates`。更新器只接受固定仓库的正式版三段式版本标签和匹配名称的 EXE，拒绝 Draft、Prerelease、异常文件大小及非 GitHub HTTPS 重定向，并按照 GitHub 发布信息中的文件大小和 SHA-256 摘要完成校验后才会尝试启动。程序不会执行 Release 说明中的网址或命令。

新版本会等待旧进程退出，再接管单实例运行。若自动启动失败，程序会显示完整下载路径并提醒手动退出、重启。DNS、代理、连接超时等原因导致 GitHub 不可访问时，会明确提示网络原因；GitHub 服务错误或请求频率限制则不会误报成本地网络故障。

## 构建

在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成文件使用版本化名称，例如 `dist\CodexQuotaTray-v2.6.0.exe`，并同时生成配套的完整 TXT 使用说明；构建新版不会覆盖旧版文件。项目使用 Windows 自带的 .NET Framework 4.8 编译器，不需要安装 Visual Studio 或 .NET SDK。
